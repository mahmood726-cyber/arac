**Author:** mahmood726-cyber  

---

## 1. Goal

Produce a pilot Tier-P RGS atlas on a stratified ~100-MA sample from Pairwise70, using the sonnet classifier in production mode. The headline deliverable is a pilot `atlas_pilot.csv` with **visible** RGS rows — i.e., MAs where k_subset ≥ 3 African-majority trials — demonstrating that the methodology produces interpretable gap metrics at meaningful scale.

The v0.1.3 audit-subset atlas produced 21 MAs but all were invisible (k_subset < 3 in every case), because the v0.1.1 trial-level sample (n=30 trials) contained only 2 african_majority classifications, each in a separate MA, giving k_subset=1 for both. v0.2 fixes this by: (a) switching the sampling unit from *trials* to *MAs*, (b) enriching toward Cochrane reviews on Africa-endemic diseases where African-majority trials are expected, and (c) running all trials within each sampled MA through the classifier.

---

## 2. Why a Pilot

v0.3 is the full atlas (n≈6,386 MAs from all 595 Pairwise70 reviews). That requires substantial compute and pre-registered human IRR validation at Makerere. v0.2 demonstrates the methodology at meaningful scale (~100 MAs × ~10 trials each ≈ ~1,000 abstracts) without committing to the full run. If v0.2 produces <10 visible MAs, the enrichment strategy must be revised before v0.3. If it produces ≥10 visible MAs with measurable gap metrics, v0.3 proceeds.

## 3. Sampling Protocol

### 3.1 Population

All meta-analyses from Pairwise70 (595 .rda files) that satisfy eligibility:  
(a) k_total ≥ 3 trials (hits `INVISIBILITY_THRESHOLD_K`), and  
(b) at least one trial Study string (or Analysis.name) resolves to a non-empty PMID via the ARAC resolver cache.

Full Pairwise70 scan yields **5,574 eligible MAs** (as of 2026-05-06).

### 3.2 Enrichment Keyword List

The following keywords are matched case-insensitively with word-boundary regex (`\b<keyword>\b`) against the concatenation of all Study strings and the Analysis.name for each MA. Any match in any field classifies the MA as *enriched*:

**Country/region names:** Uganda, Kenya, South Africa, Nigeria, Tanzania, Ghana, Malawi, Ethiopia, Zimbabwe, Zambia, Mozambique, Rwanda, Cameroon, Senegal, Mali, Gambia, Burkina Faso, Botswana, Cote d Ivoire, Democratic Republic, Sudan

**Disease keywords:** malaria, HIV, AIDS, tuberculosis, bednet, trypanosomiasis, onchocerciasis, leishmaniasis, schistosomiasis, helminth, sleeping sickness, yellow fever, cholera

### 3.3 Stratum Sizes and Population Constraint

A full scan of Pairwise70 identifies **45 enriched MAs** (k ≥ 3) — the complete universe of enriched-eligible MAs. Because the enriched universe is smaller than the target 60, the sampling is adjusted:

- **Enriched stratum: all 45 eligible enriched MAs** (no random draw needed — full census)
- **Random stratum: 55 MAs** drawn uniformly at random (seed=42) from the 5,529 non-enriched eligible MAs
- **Total: 100 MAs**

This adjustment is **not** a deviation from the scientific intent (maximise visible Tier-P rows while anchoring specificity). It means the enriched stratum is a census of all Africa-endemic-disease MAs in Pairwise70, which is methodologically stronger than a random draw from 45.

### 3.4 Sampling Seed and Determinism

`random.seed(42)` governs only the random stratum draw (the enriched census is deterministic). The sample list is pre-registered (OTS-stamped) before any sonnet calls.

## 4. Production Classifier — Sonnet

v0.1.1 calibrated the opus classifier (κ=1.000 on n=9 evaluable trial pairs vs blinded human auditor). v0.2 switches to **claude-sonnet-4-6** (or the current default sonnet model) for batched efficiency.

### 4.1 Justification

- Sonnet is comparable to opus on single-abstract extraction tasks (extraction scope is one abstract at a time, well within sonnet's context window).
- The v0.1.1 calibration framework can be re-applied to sonnet at v0.3 (Makerere human IRR audit is the canonical gold standard for both).
- Subscription-mode dispatch avoids the ~$30 per-run API cost of opus at 1,000-abstract scale.

### 4.2 Model Override

The `ARAC_TIER_P_MODEL` env var controls the model. For v0.2 production runs, set `ARAC_TIER_P_MODEL=claude-sonnet-4-6` (or the appropriate current sonnet model ID). The pipeline logs the actual model used in `sonnet_extractions.json`.

---

## 5. Phase 4 — Sonnet Calibration Mini-Audit (STOP Gate)

Before the full 100-MA pilot run, a calibration mini-audit checks sonnet against opus:

- Select 10 trials from the v0.1.1 sample where opus classifications exist in `audit_llm_outputs.json`
- Run sonnet on the same 10 abstracts using the production system prompt
- Compute Cohen's κ between sonnet and opus classifications
- **STOP if κ < 0.6** — sonnet is too divergent for production substitution at v0.2

The calibration is a gate, not a result-shopping step. The 10 trials are selected deterministically (first 10 by trial_id sort order from v0.1.1 sample). Results go to `data/v0.2/sonnet_calibration_report.json`.

## 7. Pre-Registration

The spec and `sample_list_pilot.json` are OTS-stamped **before** any sonnet call on the full 100-MA pilot run. The 10-trial calibration is a gate step (not a pilot result) so it precedes the OTS stamp. Sequence:

1. Write this spec → OTS-stamp
2. Run Phase 3 (sample selection) → generate `sample_list_pilot.json`
3. OTS-stamp `sample_list_pilot.json`
4. Run Phase 4 (calibration mini-audit) — not pre-registered data
5. If κ ≥ 0.6: proceed with Phase 5 (pilot batch)
6. If κ < 0.6: STOP, report, revise model strategy

## 9. Risks and Mitigations

| ID | Risk | Mitigation |
|----|------|------------|
| R12 | Sonnet drift from opus | Phase 4 calibration mini-audit is a STOP gate (κ < 0.6 halts) |
| R13 | PMID errors at 100-MA scale | Run PMID resolution check on the sample before sonnet; MAs with >50% PMID miss are excluded from the pilot run but retained in sample_list_pilot.json with `pmid_miss_rate` noted |
| R14 | Insufficient visible rows | Enriched stratum is a census of all 45 Africa-endemic-disease MAs; if still <10 visible, increase investigation scope to CD-number prefix matching for known Africa Cochrane groups |
| R15 | Enriched universe too small | Mitigated: 45 MAs is the full enriched universe; the random stratum compensates to reach n=100 |
