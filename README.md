# ARAC — African Representation Atlas of Cochrane

> The first cross-cutting audit of how the global evidence base — operationalised as the Cochrane Library — represents African populations, African investigators, and African patients.

## Run the pipeline

```bash
pip install -e ".[dev]"
python -m pytest -v          # 110 tests; 1 SKIP (live LLM API requires ANTHROPIC_API_KEY)

# Build a small atlas (no LLM cost — sa_only mode skips Tier-P):
python scripts/build_atlas.py --max-mas 50 --tier-mode sa_only

# Render the dashboard:
python scripts/build_dashboard.py
# → opens outputs/dashboard.html in any browser, no CDN, no build step

# Generate per-trial labels CSV (for the verification UI):
# (placeholder — full batch generator deferred; for now, hand-write or use the
#  inline TrialLabel example in scripts/build_verification.py)
python scripts/build_verification.py
# → opens outputs/verification.html in any browser
```

For the full atlas (~6,386 MAs × 5 RGS metrics × full Tier-S/A/P triad including LLM-based Tier-P), set `ARAC_ANTHROPIC_API_KEY` and run:

```bash
python scripts/build_atlas.py --max-mas 6386 --tier-mode sap
```

Estimated cost: ~$30 amortized (Opus 4.7 with prompt caching on the stable extraction system prompt).

## Pipeline architecture

```
Pairwise70 (R .rda)
       │
       ▼
Resolver (Plan 2A) — PubMed Author-Year / CT.gov NCT / acronym table
       │
       ▼ (PubMed efetch enrichment, Plan 2A.1)
       │
       ├─→ Tier-S (Plan 2B) — AACT site lookup → African country?
       ├─→ Tier-A (Plan 2C) — first/senior author affiliation → African?
       └─→ Tier-P (Plan 2D) — LLM extraction of abstract → ≥50% African?
            │
            ▼
       RGSEngine (Plan 3A + 3A.1 + 3A.2) — 5 metrics per MA × per Tier
            │
            ├─→ atlas.csv (24 cols, Plan 3A) → dashboard.html (Plan 3B)
            └─→ trial_labels.csv (21 cols) → verification.html (Plan 3C)
```
